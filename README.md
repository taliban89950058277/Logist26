# Путь — карта перевозчиков

## Запуск

Требуются Node.js 24+ и Python 3.

```sh
npm install
npm run import:setup
npm run import:data
npm run dev
```

`npm run dev` запускает Vite и API на портах 5173 и 3001. API доступен интерфейсу через Vite proxy.

Перед первым запуском создайте `.env.local` из `.env.example` и укажите ключ Яндекс Карт. Ограничьте ключ доменами приложения в кабинете Яндекса.

## Данные

- `справочник городов.xls` загружает города и регионы в локальную SQLite `data/carriers.sqlite`.
- `Список перевозчиков.xls` загружает карточки и историю рейсов. Повторный `npm run import:data` пересобирает импортированные записи из актуальных файлов.
- SQLite и локальные настройки исключены из Git.
- Совпадения юрадресов с несколькими городами помечаются как неоднозначные; неподтверждённые адреса остаются без города.
- Исходные таблицы не меняются. В текущем файле перевозчиков нет столбца телефона.
